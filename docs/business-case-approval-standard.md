## What the case must preserve

| Area | Binding requirement |
| --- | --- |
| Verdicts | Test, revise, pause for evidence, or do not pursue the current proposition |
| Meaning of “go” | Consider a bounded test—not a prediction of business success |
| Transition | Human chooses next authorised path; disagreement does not erase verdict or bypass safety |
| Teams | Act A = research team; Act B = continuation team for chosen next step |
| Case | One persistent case; Acts are views/milestones |
| Case room | Exposes the persistent case record (not equated with the whole Product Brain) |
| Diligence | Scope, sources, counterevidence, limitations, completion criteria |
| Collaboration | Persisted handoffs with ownership and consequence |
| Commerce | Investigation vs Continuation; rules before paid availability |
| Pause vs failure | Evidence-based pause ≠ platform execution failure |
| Assurance | Separate origin / evidence / execution / review / availability fields |
| Concept freeze | No business-case expansion until an authorised phase demonstrates the case |

5. Superseded docs stay in history; resolve conflicts explicitly.
