# Interactive Product Brain explorer

The homepage replaces its inert screenshot-like composition with a working illustrated example. Three independently highlighted illustration layers and eleven semantic object buttons explain evidence, specialist judgement, human approval and inspectable delivery. A fourth feedback view shows the return path and explicitly labels connected measurement as planned. Layer and object selections update the inspector and its output. Existing product routes are directly reachable.

Play/restart follows a bounded sample journey. It stops at the human gate and requires an explicit example approval before continuing. The approval changes component state only; it does not call a workspace mutation or approve a real mission. Playback pauses outside the visible scene; reduced-motion preference suppresses moving traces and layer transforms. Named controls and an object strip support keyboard and touch inspection. A restrained pointer response affects only illustration presentation.

The inspector opens the existing sample deliberation engine with real local sample calculations, alternatives, panel positions and dissent. No provider request, database mutation, production runtime, real customer outcome or automatic deployment is implied.
