# Example mission experience

The public `/how-it-works` page explains one hypothetical onboarding question. It does not run a mission or write an approval.

## Journey

1. A concise introduction and page navigation lead directly to the existing labelled mission illustration.
2. The illustration exposes the recipient, required input and handoff output. Directional arrowheads and optional playback show movement. Named catalogue contributions are explanatory, not live execution claims.
3. The decision desk keeps E-01, the three alternatives and the review challenge together. Visitors can request evidence, scope an investigation or reject a recommendation. These choices are local React state only; each reveals the next handoff and scope. Reset restores the pending state.
4. The four fixed sample documents remain downloadable with the owner decision pending. They do not inherit the visitor's exploratory choice. Downloading a file is not an external-action approval gate.
5. A measurement → supplied observation → review diagram explains the feedback loop. Baseline and actual outcome are missing, and follow-up requires the owner's approval.
6. Brief preparation and paid-pilot links provide the next conversion step.

## Boundaries

No database, authentication, billing, provider, execution or production schema changes. Keep the approved marketing illustration and shared design language. No claims of observed uplift, independent agent verification or automatic telemetry collection.

## Validation

TypeScript and production build; lint (existing warnings only). Browser review at desktop and 390px mobile. Check each of the three decision responses and reset, illustration hotspots, document selection/download, and in-page navigation. Reduced-motion behaviour is preserved by the illustration and no new automatic animation is added.

## Full illustration-led redesign

The final page uses five visible chapters: frame the mission, connect context, develop a direction, choose the next step and bring learning back. All five original workbench illustrations remain directly visible: mission, record, team, trust and learning. Chapter navigation, concise handoff summaries, a sample brief in the opening, the document shelf and the owner decision desk connect them into one journey. No illustration is hidden behind a disclosure. The page retains honest capability and provenance boundaries.
