### Text-only vendoring (added 2 November 2026)

The four rows above are vendored **text only**: `SKILL.md`, reference `.md`, `.json`, `.csv`, `.yaml` and licence files, byte-for-byte. Scripts (`.py`, `.js`, `.cjs`, `.sh`), fonts, images, HTML/CSS templates and example components were left out, so nothing executable was added; any step in these skills that runs a bundled script will not resolve here. Skills already provided by installed plugins (pm-skills, hallmark, taste, diagram-design, ui-ux-pro-max, archify) were not duplicated. `JCodesMore/ai-website-cloner-template` was not added: it exists to replicate other sites, which conflicts with this project's no-impersonation rule.
